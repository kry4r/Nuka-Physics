### Task 3.4.3 — Run training

Long-running command:

```bash
python examples/training/train_go2_ppo.py \
    --num_envs 4096 \
    --max_epochs 1500 \
    --checkpoint out/go2_locomotion/ckpt \
    --tensorboard out/go2_locomotion/tb
```

Expected wall time on RTX 4090: ~6–10 hours (consistent with IsaacGym Go2 baseline).

Sanity checkpoints throughout training:
- Epoch 50: episodic reward > 0 (random policy baseline crossed)
- Epoch 200: gait pattern visible in replay (Go2 attempts steps)
- Epoch 500: tracks commanded velocity x within 20% error
- Epoch 1000: tracks commanded velocity x within 5% error
- Epoch 1500: locomotion stable across ±2 m/s commanded velocity

### Task 3.4.4 — Continuous performance verification during training

During the training run, periodically (every 100 epochs) export perf counters and verify:
- Mean step time still < 1 ms / env-step
- No NaN / Inf injected by V2 invariants
- Energy drift bounded across episodes
- D1 determinism still holds (a side regression test runs every 100 epochs replaying 100 steps and asserting bit-exact match)

If any regress, training pauses and the regression is investigated. This is the live evidence that the v0.3 architecture holds.

### Task 3.4.6 — Determinism + reproducibility validation

Critical for v0.3 closure: same seed should reproduce the same training run bit-exactly through at least the first N steps (D1 contract is per-step; full training reproducibility may diverge due to floating-point summation in rl_games optimizer — that's PyTorch's domain, not ours).

Test:
- Run 100 steps with seed 42 twice; assert physics state bit-exact.
- Run 1000-step PPO rollout twice; assert observation tensors bit-exact at each rollout boundary.

If determinism fails at the engine level: regression; do not declare v0.3 closed.
