# 统一块下降、柔体与流体

Nuka 的生产求解器是统一增广块下降（UABD）。刚体、关节体、VBD 顶点和 MLS-MPM 网格结点通过同一套接触行交换冲量。场景中的机器人、地面、抓取物和介质共同决定块与行的关联，场景名称不参与求解路径选择。

## 模型、状态与执行

`SceneIR` 经 `CookToModel` 生成 `nk::Model`，保存拓扑、材料、几何、自由度映射和容量。`nk::Data` 按模型容量分配状态与工作区，字段由 `src/nk/model/fields.yaml` 生成。`nk::World` 管理控制、步进、重置、检查点和状态读出。

`nk::Pipeline` 按数据依赖排列后端无关的操作。CUDA 后端负责线程协作、共享内存、流与 graph 捕获；这些设备细节不进入模型或公共物理接口。

一次物理步包含以下工作：

1. 保存步初状态，形成驱动力与外力。
2. 更新关节体运动学、偏置力、质量因子和自由速度；推进自由刚体与介质预测。
3. 检测接触并组装法向、摩擦、关节限制与驱动行。
4. 构造活跃行与块的关联，执行原始块下降和对偶更新。
5. 积分位置、完成介质传递，更新接触缓存、传感器与物理诊断。

控制模式、介质类型和模型拓扑决定哪些操作存在。运行参数 `solver_vel_iters` 传入块下降迭代预算；增加预算应结合约束误差和整步耗时评估。

## 关节体自由运动

`ArticulationDynamics` 在每个关节体上计算 RNEA 偏置力 $b$ 和 CRBA 质量矩阵。标量关节的 armature 加到质量对角线，延迟处理的驱动阻尼 $C$ 形成步质量 $\widehat M=M+dt\,C$。被动阻尼 $D$ 保留在广义力中。

自由速度满足

$$\widehat M(v_{free}-v_n)=dt\,[\tau-b-(C+D)v_n].$$

浮动基的空间速度使用基体坐标系，重力变换到相同坐标后进入偏置力。外部 link wrench 在同一动力学算子中进入广义力，并在消费后清零。

矩阵保存为 $\widehat M=LDL^T$：`m_factor` 的严格下三角存单位下三角因子 $L$，对角线存 $D$。接触质量响应通过前代计算：

$$y=L^{-1}J^T,\qquad W=J\widehat M^{-1}J^T=y^TD^{-1}y.$$

系统保留 Jacobian 和质量因子，无需保存完整逆矩阵或每行的逆质量乘积。计算力矩与 OSC 控制器使用同一因子求取所需响应。mimic 约束通过坐标映射 $v=Zu$ 构造 $Z^T\widehat M Z$，投影速度后在独立坐标上求解。

## 接触与增广块下降

`NkRow` 描述端点、Jacobian、右端、柔度、冲量边界及摩擦块关系。相同 owner 上的端点贡献合并后进入块方程。法向阻抗按质量响应缩放，并加入步初法向速度；`contact_response` 为诊断保留完整接触块响应。

块下降围绕自由运动状态形成惯性目标，加上弹性和增广接触项。每个块更新原始变量，接触组更新法向和摩擦对偶变量。有限迭代误差通过接触违反、力残差及失败诊断读出。

CUDA 后端把坐标和行数据能容纳的环境交给 warp tile，一次发射执行其迭代预算。更大的系统使用相同物理方程和按 owner 组织的分阶段块更新。调度由自由度、关联项和设备资源决定。

## VBD 布料、软体与缆索

VBD 顶点以位置为未知量。惯性项与三角形、四面体或杆单元能量共同形成局部目标：

$$E(x)=\frac{1}{2dt^2}(x-\widehat x)^TM(x-\widehat x)+E_{elastic}(x)+E_{contact}(x).$$

模型烹饪生成单元、邻接与顶点颜色。每次更新组装局部梯度和曲率，求下降方向并检查步长。接触端点把顶点与刚体、关节体或其他介质连接到同一行系统，反作用由相同 Jacobian 传递。

布料的拉伸、弯曲与阻尼参数定义材料响应；迭代次数定义数值求解预算。验收需同时检查贴合、形变、接触违反和力残差。渲染使用步进后的粒子位置及相应表面拓扑。

## MLS-MPM 流体与固体

MPM 粒子携带位置、速度、质量、形变及材料状态。粒子到网格传递构造网格质量与动量，网格更新结合材料项、外力和统一接触行，随后网格到粒子传递更新粒子状态。

粒子质量与参考体积来自烹饪结果，材料本构决定流体、弹性体和弹塑性体的应力响应。接触求解作用在网格结点或由插值项组成的点端点上，刚体和关节体接收对应反作用。材料失败、网格接触溢出和耦合动量有独立读出字段。

`CookParticleBox` 和 `CookParticleSphere` 只生成初始粒子采样，返回 `ParticleLattice`。每个粒子代表一个晶格单元，质量为 $\rho_0s^3$。表面网格器从粒子密度场提取可视化等值面；它的平滑核用于表面重建。

## 接口与验证

Python 通过 DLPack 读取状态、写控制量并驱动生产 `World.step()`。状态检查点支持重置与重放。当前公开接口不提供可微仿真 Tape 或反向传播。

求解器改动通过完整场景流水线检查烹饪、创建世界、控制、步进、接触与耦合、重置和读出；影响可视化或传感器的改动同时检查渲染。物理验收关注约束误差、动量与能量记账、接触响应和时间步收敛。更换分解或求和顺序时，逐位相同不作为物理正确性的判据。

主要实现入口：`src/nk/pipeline/pipeline.cpp`、`src/phi/backend_cuda/ops/articulation.cu`、`articulation_mass.cuh`、`assemble_rows.cu`、`block_descent.cu`、`vertex_blocks.cu`、`mpm.cu`，以及 `src/scene/cook/cook_to_model.cpp`。
