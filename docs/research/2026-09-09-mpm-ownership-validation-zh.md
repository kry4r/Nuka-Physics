# MPM 粒子归属与接触容量验收

此批是后端无关的架构修复。`Model::MpmParticlesPerEnv()` 统一纯 MPM、混合 MPM/XPBD 和其他粒子模式的归属；cook、pipeline、预测/接触参数和 workspace 计数消费同一范围。纯 MPM 不生成粒子接触行，因此不为这些行预留 slots；混合场景保留全部 XPBD 粒子接触预算，刚体 manifold 和网格反作用继续执行。非法范围和接触容量不足明确失败，零接触容量不再参与无符号减法。

改造前已复核性能 spec 与 [MPM review](2026-09-09-mpm-performance-review-zh.md)。最新上游为 Newton `90c56c3`、MuJoCo `f4959d9`、Genesis `4efac5f`；前两家本次增量仅涉及资产下载及发布版本，求解实现未变。没有加入 CUDA 类型、设备分支或场景阈值。

## 完整五进程对照

复用原 180,000 粒子、110,400 节点、40 子步、240 步静置和 420 步落水。每种执行方式做五对独立进程，交替 A/B 与 B/A 顺序；每步计 GPU 完成时间，上传/下载、质量扫描和渲染排除在物理时间外。下表为各进程完整阶段平均值的中位数。

| 执行 | 阶段 | 基线 ms/步 | 候选 ms/步 | 变化 |
| --- | --- | ---: | ---: | ---: |
| eager | 静置 | 43.75075 | 41.47092 | −5.21% |
| eager | 落水 | 50.86532 | 48.37812 | −4.89% |
| graph | 静置 | 39.91202 | 36.96506 | −7.38% |
| graph | 落水 | 47.61642 | 44.63332 | −6.26% |

十对落水采样均改善：eager 每对改善 4.67%–5.01%，graph 6.20%–6.31%。物理数据区从 1,641,139,200 B 降至 71,218,432 B；模型区从 75,101,952 B 降至 221,952 B。纯 MPM 接触槽从 720,016 恢复为原刚体预算 16，没有减少真实接触或迭代。

全部二十个进程通过既定有限状态、体积、splash、减速/反作用及淹没检查；十对的完整质量报告、全程轨迹 hash 和十个末帧状态字段相同。原局部大 J、无 SDF 地板状态和耦合局限仍保留，不以字节一致替代物理质量。原场景集合 33 项通过、2 项保持 disabled；E=16 的 robot-cloth-fluid 完整 450 步 graph pipeline 通过，没有新增单测。

命令、每个进程的设备/时钟观测、原始时间分布、状态和源码身份保存在 `ownership_*`；正式汇总为 `ownership_paired/summary.json`。此批已证明容量和时间收益，CUDA P2G/活跃网格/反作用优化继续单独验收；无 SDF、多 owner、有限质量和子步多体反馈仍按规格接续。
