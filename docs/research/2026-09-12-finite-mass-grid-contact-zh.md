# 有限质量网格接触与动态夹爪

更新：2026-09-12。当前实现接续 `775d168` 的 MPM 预测、交换、提交边界。共同接触的生产管线与独立不变量通过；动态夹爪以视觉预览发布，空间精度门失败且收敛未完成，不能据此宣称全部多介质耦合或性能优化完成。

## 物理路径

MPM 活跃网格节点作为有限质量端点进入通用 ContactBlock。交换阶段按节点、边界、碰撞体的固定顺序统计和压缩接触，保留容量内的全部候选，不再只选择最深 owner。共同求解器同时更新网格速度、刚体速度和关节速度，提交阶段再做 G2P 与材料更新。反作用读出只汇总已求解的冲量，不再次施加反作用。

每个接触包含法向及两条切向行。网格端点提供节点逆质量，刚体提供世界坐标惯量，关节端点使用完整广义质量响应；同一 articulation 不同端点之间的交叉项仍参与有效质量。双方 Jacobian 使用同一网格位置作为力矩参考点。固定边界的冲量与关于世界原点的角冲量单独记录。

网格接触使用无恢复系数的单边速度约束及库仑摩擦，不添加位置伪冲量，也不移动背景网格坐标。原有刚体、粒子接触继续使用其已有接触材料定律。这里没有完成连续布面接触、自碰撞、CCD、不同介质网格之间的直接交换或多材料分离模型。

## 容量与公共接口

默认每环境接触池容量为 `min(网格节点数, 27 × MPM 粒子数)`。该池允许一个节点占用多个接触；它不是每节点 owner 截断。作者可通过 `MpmMaterial.contact_capacity`、`SceneBuilder.add_media(mpm_contact_capacity=...)` 或 C 函数 `nuka_scene_set_mpm_contact_capacity` 显式设置，并保存到 `.nks`。

| 公共字段 | 类型与含义 |
| --- | --- |
| `GRID_CONTACT_ATTEMPTED` | uint64，最近公共子步尝试产生的接触数 |
| `GRID_CONTACT_RETAINED` | uint32，最近公共子步保留的接触数 |
| `GRID_CONTACT_PEAK` | uint64，自 reset 起的尝试接触数峰值 |
| `GRID_CONTACT_OVERFLOW` | uint64，最近公共子步超出池容量的数量 |
| `MPM_BODY_IMPULSE` / `MPM_BODY_ANGULAR_IMPULSE` | 完整外步的刚体／关节 owner 反作用；角冲量参考刚体 COM 或关节 link 原点 |
| `MPM_BOUNDARY_IMPULSE` / `MPM_BOUNDARY_ANGULAR_IMPULSE` | 完整外步的固定边界反作用；角冲量参考世界原点 |

字段枚举在原有 48 个字段之后追加，旧 descriptor 布局保持不变。公共 wire dtype 增加 `2 = uint64`，Python 下载和 DLPack 均保持 64 位。容量不足设置 `ENV_STATUS_GRID_CONTACT_OVERFLOW`，该环境的物理结果不可验收；操作执行成功不等于环境状态有效。外步状态保留任一子步的错误，不能只检查最后一个子步的 overflow 数。手工构造的 MPM 模型也必须提供非空接触池。

## 已发现并修复的数值问题

对称撞击用例采用单位粒子质量、完整二次插值模板、初始速度 −1 m/s、无重力／摩擦、一或两个有限质量 owner。接触覆盖的节点质量为 7/8，剩余 1/8 保持自由运动。解析共同速度为 `−(7/8)/(7/8 + owner数 × owner质量)`。

原始 512 次迭代在质量比 1000:1、两个 owner 时未收敛：速度残差为 `3.57649e-4 m/s`，超过 `2e-5 m/s` 门槛。提高到 4096 次后速度收敛，却暴露出反作用与速度增量之间的累加漂移，最坏约 `1.68e-4 N·s`。两份失败的源码和可执行文件均保留。

通用速度更新现采用补偿累加，覆盖网格、粒子、刚体线／角速度和关节广义速度；同时取消“记录微小 lambda 但不施加其增量”的绝对冲量截断。舍入误差工作区由后端定尺寸，核心只携带容量和不透明字节存储。接触块求逆先按最大对角量归一化，避免很小节点质量导致行列式运算溢出。

修复后，质量比 1／10／100／1000、单／双 owner、`dt=1e-4/2e-4 s` 的全部组合通过原速度、线／角动量、动能非增长、双方冲量一致性和 reset 条件。4096 次预算下最大速度残差为 `6.84260e-7 m/s`。这证明指定预算下的物理一致性，不表示 512 次预算已经足够，也不构成性能提升。

几何验收门在网格细化时保持固定的 2 mm 绝对值；它是粗网格半个单元的精度预算，不随着候选网格改变。材料历史、体积、反力、速度残差和线／角动量仍分别验收。角动量包含 APIC 仿射项，重力矩使用控制采样间的梯形积分；执行器做功同样是控制采样估计，不能据此宣称完整能量闭合。

CSV 的形状位移 RMS 去除质心平移，仍包含整体转动。composer 另以同一材料粒子的初始与当前坐标做最佳刚体配准，去除平移和旋转后独立量测残余形变及末态波动；原有门保留，配准后的形状与收敛比较须同时满足相同绝对预算。粗网格录制的末态平均位移 RMS 为 0.794 mm，配准后为 0.694 mm；补充分析仍正确判定其 3.996 mm 侵入失败，不能作为物理验收通过发布。

demo 提供 `--contact-capacity` 作者容量参数，使用公共接触池契约；任何子步溢出仍使捕获失败。`grid_capacity_complete_01` 对比 68,921 与 32,768 容量，全长 337 帧的 `states.bin` 和 CSV 逐字节一致，status 和 overflow 均为零。`grid_capacity_prefix_01` 对比细网格默认 531,441 与显式 32,768 容量，已有的 13 个状态一致。容量对照只证明未溢出时的资源配置等价，不证明粗网格的几何验收通过，也不作为求解器性能收益。生产回归与部分 demo 捕获并行运行，其计时不能作为独占 GPU 的性能分母。

细化到 2 mm 后，18 mm 轻压目标只有约 0.04 N 反力，中央宽度几乎没有变化。新的验收补充要求轻压中央宽度减小至少 0.05 mm，并存在至少 0.01 N 的同时双侧反力，避免把没有实际加载的静置称为弹性恢复。采用 12 kPa 屈服应力、16 mm 目标的候选在 1.8 mm 网格中出现少量局部塑性，最大历史约 0.00308，失败前缀保存在 `gripper_load_grid0018_01`。随后仅把轻压目标放松至 16.5 mm，所有网格和步长对照使用相同参数。

`gripper_loading_frozen_02` 的作者配置为 120 Hz 控制采样、2.8 s 完整循环、64 个公共子步与 32 次速度迭代，公共物理步长为 `1/7680 s`。强压目标为 4 mm，屈服应力 12 kPa，其余材料参数保持 E=50 kPa、ν=0.25、硬化 7.5 kPa 和密度 1000 kg/m³。这是显式记录的新加载输入，不与旧输入计时比较。32 次预算须通过加倍迭代对照，步长和空间精度也单独检查；两支视频计划以 24 fps 回放同一组状态，形成 5 倍慢动作。

`gripper_load_grid002_03` 与 `gripper_load_grid0018_03` 在强压时再次超过空间门：2 mm 网格在 t=1.7 s 已达 2.834 mm 侵入，1.8 mm 网格在 t=1.9 s 已达 2.686 mm。失败前缀、运行中二进制哈希和中止原因均已保留；这两组不用于正式视频。随后保持控制、材料和 0.2 mm 接触带不变，采用 1.2 mm／1.0 mm 网格与 128 个公共子步继续检查空间精度，物理步长为 `1/15360 s`，2 mm 侵入门保持不变。

长捕获的恢复检查发现 demo 虽设置 graph 模式，原步进调用却仍为 eager 的 `World::Step()`。现改为调用 `StepConfigured()`，两种模式使用同一 operator 序列，并在捕获配置与完成记录中保存模式和实际 graph replay 次数；composer 同时核对该执行契约。此项是应用调用修正，不作为引擎性能收益。

捕获现在通过现有 `Data::DownloadPersistent`／`UploadPersistent` 边界保存材料、关节及接触历史，并单独保存曲线积分与上一个控制力样本。两个交替断点带有完整性校验，恢复校验可执行文件、配置及 `.nks`／`.nka` 场景对。`gripper_recorder_acceptance_02.json` 已验证完整 337 状态的 eager 与 graph／中断恢复对照：截断 frame 228 的最新断点后，成功回退到 frame 216，从 frame 217 继续；恢复进程实际执行 120 次 graph replay，双方 reset 通过，完整 `states.bin` 与 `metrics.csv` 逐字节一致。该对照使用 4 mm 网格，只证明执行和恢复一致性；完整物理验收仍须通过独立物理门与分辨率／步长／迭代比较。

Windows 文件落盘检查复现只读描述符的 `_commit` 返回 −1，改用读写描述符后返回 0。该条件编译分支修正后，Linux 重新构建的 demo 与引擎库哈希均保持一致；这项文件检查不代表完整 Windows 物理管线验收。

Newton 1.7.0.dev0／Warp 1.17.0 的 CPU XPBD 实跑使用已安装参考环境：源码匹配 `1128af71407e002d15a8cfb180b35158cf64c42f` 归档，与本批 review 的主干 revision 不同。16 组保持相同质量和中心法向条件，采用二进制可精确表示的球／盒相切几何、4096 次迭代、0.5 松弛、零摩擦／重力。全部产生预期接触，最大线动量误差为 `2.840e-7 N·s`；速度相对硬解析值最多偏离 `9.275e-4 m/s`，未达到 Nuka 的速度门。float32 位置纠正与小位移精度是该对照的限制，不将它作为逐值真值。原始实跑日志及安装源码逐文件哈希保存在 `reference/newton_cpu_receipt_02/`。

两支 H.264 MP4 均为 337 帧、14.041667 s，完整解码检查通过；近景 GIF 为 640×400、169 帧循环。已检查轻压、恢复、强压、释放及末态的 8 个关键状态，两路构图完整。主页第五行布料卡片替换为夹爪预览，浅色/深色页面与本地媒体链接检查通过。成片与源码身份见 [录像清单](../media/demo_recordings.json)；本地 `gripper_visual_acceptance_01.json` 还验证默认 composer 仍拒绝该空间失败。用户检视单独保留。

用户要求比较旧视频后，使用已保存数据补查了三种场景。板压 `v3` 在 t=2.9 s 的上压板内表面为 85.000 mm，最高粒子中心为 89.007 mm，穿入 4.007 mm；下压板无粒子中心穿入。旧板压验收没有单列穿透门，因此旧视频通过不等于零穿透。Bunny 的已发布结果为 2.393 mm，原预算和接触包络均为 5 mm；其早期小包络版本曾超过预算。

夹爪的 3.996 mm 峰值出现在 t=2.0833 s 的释放段。对保存的碰撞体位姿做独立盒体距离计算，在相同指垫复现 3.996257 mm：该帧有 331 个粒子中心在此盒内，最深粒子位于厚度中面附近。指垫半厚度为 4 mm，最近表面距离在盒内不会超过这个值；该指标不能检测完整穿过指垫的路径，也不能解释成“误差最多一个网格”。局部几何诊断保存在 `demo_penetration_comparison_01.json`。

共同原因是网格节点的单边速度条件没有保证插值后的粒子位置满足碰撞几何：G2P 同时混合受约束与未受约束的邻居速度，当前网格接触也没有粒子表面的连续非穿透条件或几何恢复。大平压板、厚兔子和薄指垫的采样条件不同；bunny 还采用较大的提前接触包络。新旧算法与场景参数均有差异，尚未进行同输入的新旧接触消融，不能把全部差异归因于有限质量求解器。

后续需补连续边界／插值端点与穿越诊断，在共同质量与动量契约下验证。单纯增加速度求解迭代数无法保证修复空间误差，扩大接触包络也不是未经验证即可采纳的解决方案。本次视觉发布不关闭这些缺口。
