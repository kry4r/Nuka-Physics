# 渲染表面重建与场景更新验收

2026-09-11。固定水体输入和画质，旧新交错各五个独立进程，完整帧平均完成墙时的中位数由 **676.341 降至 192.701 ms（−71.51%，3.51 倍）**。128 帧 RGBA/PNG、八帧 profile 图像及各进程像素摘要一致。批量刚体相机基本持平，E16 物理→相机平均完成时间有 1.45% 回退；本批没有证明着色 kernel 提速或动态介质传感器已完备。

## 改动与分类

后端无关的渲染资源生命周期改造：增加场景更新接口，按完整几何与属性比较复用未变化 BLAS，保留 TLAS/AOV 工作区；HDR 按真实 texel 内容和设备失效。同尺寸换图、增删实例、材质、法线/UV/颜色变化均能更新。studio 和水体使用同一个接口。

CPU 实现优化：持久线程池并行独立核计算、密度采样、法线和三角朝向。每个邻域的累加次序、共享边编号和三角次序保持；嵌套调用串行，异常返回调用线程。CUDA 资源管理留在后端，没有改变 traversal、着色、物理算法或质量预算。

固定 robot-cloth-fluid benchmark 补充 physics→sensor、render-only、全部 AOV 与 reset/状态等价观测。最初 sensor 观测把异步提交墙时误标为完成时间，旧输出保留；正式 v2 将提交分布、GPU interval 和最终同步后的完整批次墙时分开。下面 sensor 均为完成时间。

## 质量与回归

fluid mesher、two-level 场景生命周期、纹理、C ABI coupled/camera/multi-env、64 个代表 scenario、Python coupled/reset、公共 graph 和 E16 N=1/2 完整管线通过。状态与逐步 wrench 保持；water/jelly、MPM transfer、关节/刚体及 cloth/fluid 均包含在既有管线中。scene update 的定向 memcheck/synccheck 为 0 errors；无 CUDA 核心和 host render 构建通过。

保留历史失败 `RenderWorldRtBeauty.OpaqueBeautyNoOpChecksum`：旧新实际值均为 `17660401081676737862`，旧断言为 `15275657819673905153`，两版 PPM 逐字节一致。其余九项 beauty 通过。本批没有改校验值，也不报告全套零失败。各向异性默认参数在米制小池生成空网格的旧问题同样保留；按核半径归一化参数后的旧新网格一致，没有改正式水体参数。

已有批量相机仅渲染 authored rigid visuals，动态粒子表面尚未接入；水体/studio 的动态介质画面通过不等于 sensor 的全介质支持。多环境/多相机、动态表面传感器和着色热点继续保留。

## Profile 与证据

八帧 Nsight 窗口中 cudaMalloc/cudaFree 各由 2,418 降至 446 次，LbvhPairQuery 由 98 降至 18 次。Beauty kernel 总时由 303.892 变为 313.517 ms，没有 kernel 加速结论。树构建仍生成无用 pair output，后续单独优化 CUDA 实现。包含 CPU 工作期间 GPU idle 的完整帧 event interval 不能当作 kernel busy。

证据根为 `out/validation/render_refresh_20260911/`：`five_process/summary.json`、`records.json`、逐进程命令/RSS/状态/AOV；`profile_comparison.json`、两份 Nsight 数据；`opaque_anchor/`、`aniso_scale/`；验收日志和帧身份记录。旧新二进制保存在 `baseline_v2_frozen/`、`candidate_v2_frozen/`。候选源码 SHA-256 为 `a5cb7878d42adbf7be429e7603443658687dc885e77dffbaea2799353c706757`，恢复时逐文件核对记录在 `resumption_identity.json`。五进程测量使用冻结的静态链接程序，随后未构建的材料修改不参与本批对照。

本批按最新顺序收口渲染数据流优化，继续通用弹塑性材料、有限质量夹爪接触及 demo；demo 后继续性能和完整多体耦合，原 spec 的其余工作保持未完成。
