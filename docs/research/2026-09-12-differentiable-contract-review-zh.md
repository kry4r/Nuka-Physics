# 可微前向、参数和生命周期契约审计

两支弹塑性录像及主页排版完成后，按用户最新要求继续性能、耦合和可微工作。现有可微代码不能直接当作生产接触管线的梯度：它重组了一条显式阻尼的无接触 PD→ABA→积分序列，而生产 World 使用共同子步、隐式阻尼及接触求解。浮基位姿伴随、完整 checkpoint、任意树大小和设备内梯度交付也未完成。本报告保留这些缺口，不将接口修正计为完整可微能力。

## 已实施的边界修正

- `nuka.autograd.step` 的未记录反传此前返回全零。现在在启用求导且输入需要梯度时，于修改目标或推进世界之前明确拒绝；`torch.no_grad()` 下继续运行真实生产前向并返回独立快照。既有录制 PD API 的文档明确其阻尼和浮基位姿限制。
- `nuka_world_set_gravity_z` 此前只写旧 host 配置，生产 World 不读这个值。现在由后端无关 World 更新共同算子参数，保留 X/Y 与现有状态，改变值时同步并失效旧执行图，相同值不重建。
- `nuka_world_set_link_mass` 此前只更新第一个环境的惯量，并接受正无穷。现在要求有限正质量，使用同一 COM 固定参数化更新所有环境的模型设备字段，同时更新模型与质量参数 host 数据。算子仍使用同一质量矩阵和地址。
- Tape 以不会复用的 world handle 校验存活，避免世界销毁后反传或读出悬空设备地址；尚未实现的多环境录制在创建时拒绝。

这些改变属于后端无关的公共参数/生命周期架构与 Python 求导契约修正；没有改动材料方程、接触算法、默认控制或默认执行计划，不作为速度收益。CUDA 传输经过已有 buffer/backend 接口，core 不新增 CUDA 类型。

原源码和库已冻结于 `out/validation/autograd_contract_20260912/baseline_complete/`，库 SHA-256 为 `07c624772fa4ed2bed0ade471aea6b35803785425a13b9f6a860c5b4f27e4de9`。扩展既有 robot–cloth–fluid 公共 pipeline 后，旧库实际接受非有限运行时参数的失败已保留。验证脚本的两次字段名错误另行保留，不作为物理失败证据。

## 后续依赖

1. 材料性能先用现有塑性冲击完整回归定位，再对同输入完整生产轨迹测量。首个 Nsight Systems 记录中，返回映射占 kernel 时间 36.43%，应力/传输记录准备占 34.30%；分别使用 106/74 registers、0/14,864 B shared，无 local spill。该输入只有 33 个 128-thread block，不外推到大型 demo 吞吐。数据在 `out/validation/material_performance_20260912/`。
2. 优先检查重复标量归一化和谱分解算术成本，保留双精度、正体积检查、收敛判据和失败语义。不引入缺少外部状态写入失效规则的跨步应力缓存。物理门和五进程完整性能通过后才采用；回退候选保留。
3. MPM 预测/接触/提交必须接入已有共同 ContactBlock，保留所有活跃 owner，使用同一虚功关系读速度和写冲量，包含有限质量及共享 articulation 交叉项。接触物理变化单独验收，再冻结新性能分母。
4. 可微录制委托生产 World，checkpoint 覆盖持久状态、控制、参数与 warmstart；反传后恢复前向终态。补全隐式阻尼、浮基位姿和实际关节变换的伴随，再处理接触活动集/摩擦/法向支持范围和设备内梯度。旧 24-link 固定工作区和隐式 `[1:]` 映射按拓扑改造，不能用静默零梯度掩盖未支持输入。

两支录像、主页和本报告只完成各自所述范围；总规格及完整多物理耦合保持未完成。
