# 弹塑性材料计算与完整管线性能

两支弹塑性演示与主页已通过 `7c3da5d` 发布。本文记录随后对通用 MLS-MPM 材料路径的性能工作；压板仍是规定运动边界，兔子仍使用网格速度投影与逐区间反作用。性能比较不将这些路径当作多 owner 有限质量共同接触已经完成。

本批沿用 [可微契约审计](2026-09-12-differentiable-contract-review-zh.md) 中复核的 Newton `c7e7ea74da529028cdf877af9df0ad40f07012f2`、MuJoCo `617b083665177cbef78a9b7a6aada0e7a946a92c`、Genesis `70199bce0d27da9fdcfb8d033269ef4e53d78f8c`。这是源码对照，不是新三引擎匹配仿真。材料质量仍由独立闭式解、客观性、塑性体积、守恒与演示中已冻结的时间步/网格收敛预算判断。

## 计时与分母

两支现有 demo 新增可选 `--perf-json`，沿原有 `World::StepConfigured`、控制、反力读回及完成边界采样。CUDA 事件只分配一个采样区间的容量，区间完成后回收使用，不新增逐算子或逐步同步。报告分别保存 World 步完成时间、host 调用时间，以及含原有控制/读回的区间墙钟；CPU 粒子分析、捕获写盘和渲染位于该区间之外。完整进程墙钟另由运行器记录。

首个真实物理区间单列，其余区间用于 steady 汇总；没有额外推进或丢弃物理状态。每版使用相同计时代码、材料/几何、时间步、graph 配置、采样和完整 reset。每个进程保存全程位置、物理测量、配置、命令、源码与二进制摘要。GPU 完成时间含执行图调度间隙，不能改名为 kernel busy time；进程中位数与进程内 p50/p95/p99 分开统计。

模型与三段 Data arena 字节按布局计算。事件数量和 host 样本容量明确报告；CUDA 不公开事件的设备分配字节，标为 unavailable。`cudaMemGetInfo` 是整张设备在采样点的空闲量，包含其他进程，不能作为精确进程峰值。

计时代码与 `division_frozen` 编译验证的源码相同；恢复的材料/后端源码仅有换行差异。该版两支完整 demo 的 `positions.bin`、`metrics.csv` 及兔子的 `material_state.bin` 与已发布 v3 捕获逐字节一致。核对见 `timing_instrumentation_acceptance.json`，因此可单独采用计时工具；该结论不采用任何候选算术改动。

证据保存在 `out/validation/material_performance_20260912/`。`division_frozen` 是除法分母；各候选的源码、库和完整可执行文件保存在同名 `_frozen` 目录。原来的小型完整冲击/reset profile 及其真实二进制另存于 `normalizer_attribution_frozen`，不以替换动态库伪造静态链接测试的历史版本。

## 算术改动与初测

算术候选复用归一化标量的双精度倒数。Jacobi 矩阵已按最大元素归一化，因此旋转半径有界；平方范数为正常 double 时直接开方，平方落入次正规范围时继续使用 `hypot`。保留 double、16 次扫掠上界、原正交残差、正体积与失败不提交语义，不裁剪奇异值或塑性历史。以下是已冻结的实验，生产材料代码恢复原算术。

这部分属于后端无关的材料数值计算改写。实验增加的一项闭式剪切检查覆盖正常尺度和 float 最大值/次正规值共存的输入，直接由三个已知奇异伸长计算能量和等效应力。既有材料闭式解、旋转客观性与完整两环境塑性冲击/reset 均通过。该检查随候选源码保留在本地冻结包中。

| 同输入完整压缩初测 | GPU 完成均值变化 | 含控制/读回的区间墙钟变化 | 全程粒子位置最大差 |
| --- | ---: | ---: | ---: |
| 只复用倒数 | −4.31% | −2.95% | 27.68 μm |
| 同时简化有界范数 | −4.95% | −2.92% | 45.77 μm |

两版独立物理检查通过。第二版卸载后平均高度差 0.358 μm，最终塑性均值/耗散相对差约 `2.59e-7`，峰值反力相对差 `7.91e-6`，模型/Data 容量不变。这些单次结果尚不足以完成 spec 的五进程性能验收，也未达到主要目标 10%。两版完整捕获保留，不把 GPU 局部变化当作整体速度结论。

比较前固定的附加算术差异预算位于 `arithmetic_quality_budgets.json`：全程粒子最大差 ≤2% dx、RMS ≤0.5% dx，刚体位置差 ≤1% dx、姿态差 ≤0.5 mrad；塑性/耗散及积分量差 ≤0.25%，峰值力差 ≤1%，最终高度差 ≤1% dx。原演示物理门同时执行，不能只满足前后相近。

计时工具首轮的字符串拼接编译失败，以及汇总脚本一次 NumPy bool 序列化错误均保留。后者的两次物理运行已完整成功，修复汇总后直接分析原捕获，没有重新跑物理。这两项是工具错误，不是材料失败。

## 完整输入热点与 CUDA 调度实验

第二版的完整压缩 Nsight Systems 记录覆盖 36,864 个物理区间及 reset：返回映射平均 119.024 μs，占 kernel busy 的 29.24%；应力与传输输入准备平均 108.579 μs，占 26.68%。二者分别使用 106/72 registers，应力准备还使用 14,864 B shared；均无 local spill。该结果来自真实 40,960 粒子输入，不外推小型 33-block 冲击测试。

`separate` 实验将应力求值与记录打包分开，复用已有 `mpm_particle_stress` scratch，按设备资源查询选择材料 kernel 的线程块。完整压缩 GPU 均值反而增加 13.96%，含控制/读回墙钟增加 9.62%。小型 jelly 输入的应力/返回映射分别选出 896/512 线程块，只发射 5/9 个块；较高的理论 occupancy 没有带来较低延迟。`active` 再将实际工作量纳入选择，压缩 GPU 降时 3.48%、区间墙钟降时 3.84%，仍不足以采用。

两版完整压缩位置与物理指标相对 `spectral` 逐字节一致，拒绝原因是性能。`separate` 通过既有全部 MPM/MLS-MPM 场景选择及无 CUDA core 构建，但这些检查不能转记到后来的算术版本。两项 CUDA 修改均已回退，源码和二进制保留。

理论 occupancy、register/shared 资源与实测 achieved occupancy 不混同；硬件计数器访问返回 `ERR_NVGPUCTRPERM`，没有测得带宽或 achieved occupancy。`rotation_resources.log` 含多个目标架构，不能引用首个架构的寄存器数量作为 RTX 5080 结果；目前没有证实该候选降低了实际设备的寄存器使用。

## 四元数算术实验与拒绝结果

`rotation` 将 Jacobi 右旋转积累为缩放 double 四元数，再重建右奇异向量，CUDA 调度恢复原实现。完整压缩 GPU 均值降时 6.24%、区间墙钟降时 5.19%，最大粒子差 26.063 μm，满足该场景预先固定的差异预算。随后完整兔子比较失败：

| 兔子完整运行指标 | 实测 | 预先固定预算 |
| --- | ---: | ---: |
| 最大粒子位置差 | 0.939512 mm | ≤0.10 mm |
| 粒子 RMS 位置差 | 3.228 μm | ≤25 μm |
| 最大刚体平移差 | 78.314 μm | ≤50 μm |
| 最大刚体旋转差 | 1.250 mrad | ≤0.5 mrad |
| 最终中心高度差 | 1.231 μm | ≤50 μm |
| 最终塑性应变/耗散相对差 | 约 8.42e-6 | ≤0.0025 |

两次兔子仿真各自通过原 demo 的独立绝对物理门；失败发生在附加的同质量轨迹比较。分母/候选进程分别耗时 199.338/189.428 s，GPU 均值下降 4.786%、区间墙钟下降 4.568%，但不能据此宣称已通过同质量优化。原始轨迹和 `rotation_bunny/comparison_01.json` 保留，不调整预算。

当前没有材料性能候选获得采用，没有执行五进程性能验收，也没有完成 spec 的主要 10% 收益目标。失败候选与仅为候选加入的测试已从生产工作区恢复，`rotation_rejection.json` 记录冻结包核对与恢复身份。保留可选完成计时工具，继续从已测热点和共同接触缺口推进；完整多体耦合与生产前向可微回放仍未完成。
