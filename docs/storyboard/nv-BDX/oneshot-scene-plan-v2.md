# BDX 一镜到底场景施工规格 v2（controller 设计，2026-07-04）

v1（oneshot-scene-plan.md）首次落地被 owner 否决。v2 = 吸收失败教训 + 逐格重读分镜草图
（bdx-sb.png / bdx-sb.md）+ owner 新指令（**木楼梯只需两阶**）后的重写。本文件对场景
subagent 是**唯一约束性任务书**。

## 0. v1 为什么失败（每条都必须在 v2 里反着做）

1. **孤岛布局**：四区散在无限大平地上、间距远、特征小 → 读不出"一个地方"。
   v2：**紧凑连续工坊走廊**，四区首尾相接，总长 ~4.6m，两侧木板墙缝合空间。
2. **尺度失配**：楼梯 rise 4cm、门框细杆，在镜头里读不出来。
   v2：所有道具对 0.35m 鸭子**放大存在感**（粗立柱、厚横梁、大吊板——见草图 D04 石板尺寸）。
3. **分镜取向错**：楼梯朝 -x 在鸭背后，镜头永远拍不到"走下楼梯"。
   v2：**楼梯沿 +x 行进方向下行**，门框横在楼梯正上方（草图 D01：机器人在梯上时头已顶布）。
4. **compose 叠塌**：门框梁掉落散架成柴堆。v2：门框三件全 static，逐件放置，加载后 settle
   probe 断言 static 件位姿零漂移。
5. **背景一团空**：v2 有墙、有背板、有道具、HDRI 天光 + 暖主光。

**引擎底座（v2 才可用，v1 时没有）**：MpmXpbd 单 world 布+砂共存；布↔刚体 box 接触
（接线法见 §3）；多碰撞 geom/link；平板鸭脚 + FK 修复；渲染 pose-source/发灰/黑帧已修。

## 1. 世界与尺度

+z up，行进方向 +x，单位米。鸭：站高 0.35，base_z 0.196，质量 2.1kg，平板 box 脚。
场景 = **室内工坊走廊**：内宽 1.1（墙内沿 y=±0.55），墙高 0.8（低机位镜头里填满背景，
又不挡顶光），总长 x∈[-0.6, 4.6]。地面大板 x∈[-1.5, 6.0]×y∈[-1.5, 1.5]（**必须远超
一切机位视锥**；相机 z 始终 >0.08，防 studio-floor 灰板泄漏——已知预存 LOW）。

## 2. 分区布置（精确坐标，subagent 照建后可微调 ±10%，但拓扑关系不许变）

### Zone A 两阶木梯 + 门框垂布（D01）x∈[-0.6, 0.9]
- **出发平台**：x∈[-0.6, 0.10]，台面 z=0.10，全宽 0.9（木板材质）。鸭 spawn (−0.20, 0, 台面+0.196)。
- **两阶下行**（owner：只要两阶）：
  - 阶1：x∈[0.10, 0.26]，台面 z=0.050（rise 0.050）
  - 落地：x≥0.26，z=0（**末阶 rise 0.050→落差诚实产生"踏空一晃"beat，不做假动画**）
  - 阶宽 0.7，两侧配粗楼梯侧板（斜置厚木板，草图 D01 左侧那种存在感）。
- **门框横在楼梯正上方** x=0.30（鸭下末阶时头恰在布下，对齐草图）：
  - 两柱 0.08×0.08×0.55 @ y=±0.38（落地 z=0 起）；横梁 0.90×0.08×0.08，梁底 z=0.46。
  - **布 = 搭在横梁上的垂帘**（草图画的就是布**搭过梁**，不是钉死）：0.55(宽 y)×0.50(长)，
    spacing 0.02（≈28×26 粒），**前垂 0.28 到 z≈0.26 / 后垂 0.16**，靠布↔梁接触+摩擦挂住。
    鸭头(0.40 高，在阶1上)穿过时必顶起鼓包+拖曳回落。
  - fallback（仅当 drape 实测滑落且调摩擦/配重不救）：给 cook 加**通用** pin 边模式
    （free/perimeter/top_edge 三档），顶边 pin 在梁上。先试 drape——它才是草图的样子且零引擎改动。

### Zone B 碎石地 MLS-MPM（D02）x∈[0.9, 2.3]
- **满走线宽碎石床**：浅槽 x∈[0.95, 2.25]×y∈[-0.35, 0.35]，深 0.03，槽沿与地面齐平
  （沿=泥土材质缓坡，读作"地面上一片碎石"，**不是木托盘**——草图里碎石就是地面）。
- granular MPM（model_kind=4 DP，φ=34°，ρ≈1600）：spacing 7-9mm 起步（~6-9 万粒），
  按显存/步速实测收敛；MPM 域墙=槽 AABB，+z 开放。
- 槽外向 Zone C 方向撒稀疏**刚体**卵石过渡（草图 D02/D03 的碎石渐薄连续感）。
- 验收=脚印持久凹痕（离步 3s 深度 ≥5mm）+ 挤开/溅散不液化。

### Zone C 小物件微距区（D03）x∈[2.3, 3.2]
- 硬泥地。走线上密集散落 **~45 个自由刚体** x∈[2.45, 3.05]×y∈[-0.20, 0.20]：
  卵石（球/凸包 r 8-15mm）、螺栓（capsule r4×L18mm）、垫圈（薄 box）、螺母（小 box）。
  金属件金属材质、卵石石材质（movable 材质渲染已修，v1 的白球不会再现）。
- 验收=静置不抖（settle 后 max|v|<0.01）；扫过时有物件被勾飞（v>0.3m/s）翻滚弹跳不穿模。

### Zone D 绳吊石板（D04）x∈[3.2, 4.3]
- 门式横梁：两柱 @ x=3.75, y=±0.50，梁沿 y 向 @ z=0.72。
- **吊物按草图做大**：石材质板 0.22(y)×0.05(x)×0.13(z)，~0.6kg，**板底 z≈0.29**（鸭头 0.35 必撞）。
- 悬挂 = 树状 articulation（无闭环）：梁锚(static) → **绳链 7 节**（capsule r0.008、seg 0.05、
  全同轴 **revolute-Y**（摆平面=行进 x-z；spherical 会被 cook 丢弃，v1 坑#1）→ **刚性 V 轭**
  （**单 link 双 capsule geom**，用多 geom/link 新能力，从链尾分叉到板顶两角——视觉上=草图的
  双绳吊挂，拓扑上仍是树）→ fixed → 石板。
- 验收=撞后沿 x-z 弧摆 ≥15°、鸭受反作用（见 §6 双 sink 探针）、绳不散不抖。

### Set dressing（草图留白处按"工坊"补）
两侧木板墙+立柱（每 0.9m 一根 0.08 方柱）；平台后背板墙；墙根走线外放 3-4 木箱/木桶
（y|>0.35）；一面墙挂工具板（平板贴图 box）。地面材质分段：平台/梯=木板 → 落地起=夯土
→ 碎石段 → 夯土。光：HDRI 天光(现有 sky_2k) + 门框上方暖主光感（材质/曝光调，非新灯系统）。
素材用已入库 CC0 集（wood/gravel/stone/metal/fabric/dirt——dirt 这次必须用上）。

## 6. 验收门（顺序执行，前门不过不进后门）

1. **cook 门**：全场景单 cook 无 throw；n_mpm/n_xpbd/刚体计数打印合理；金丝雀四联
   （Go2 0.923080623 / cloth FNV 777503423208024307 / MPM 精确值门 / scenario+import 套件）全绿。
2. **settle 门**（600 步 PD 站立）：static 道具位姿零漂移（尤其门框三件、梁、柱）；布搭梁上
   稳住（600 步末 min_z∈[0.24,0.30] 且不滑落）；砂床沉降无逃逸无 NaN；小物件 max|v|<0.01；
   石板静垂 |v|<0.01；鸭 base_z 正确、0 摔。
3. **choreo 探针门**（脚本化位姿驱动穿场，不等策略）：
   - 布：头过门时布 min_z 抬升 ≥0.06 且回落摆动；
   - 砂：踩过后凹痕深 ≥5mm 持续 3s；
   - 小物件：≥3 件被勾动 v>0.3m/s，落地弹跳静止，无穿模；
   - 石板：推头撞板 → 板摆 ≥15°，**同一步内鸭 link qdot 同时吃到砂 grid 反力与布/板
     contact-row 反力时二者相加**（= hybrid 审查遗留的双 sink 经验探针，在此关掉）。
4. **render 门**：§4 全部站位出帧，**controller 逐张 Read 验收**（铁律）；此前 subagent 自己
   先逐张看并列缺陷清单（v1 教训：agent 报"✅"与图面不符=直接打回）。
