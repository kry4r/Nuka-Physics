# LIBERO visual references

These two 360 × 360 RGB images are the reference inputs used by
`examples/demo/libero_pi05_play.py --histogram-matching`.
They contain the LIBERO Spatial black-bowl task's agent and wrist camera views,
oriented for policy input. Use `--histogram-reference` to supply another directory
with the same filenames. Raw renders and comparison images are local run output.
